Q01BásicoJava y JVM

¿Qué es Java y por qué se utiliza en QA?

RESPUESTA EXPLICADA

Java es un lenguaje de programación de tipado estático que se compila a bytecode y puede ejecutarse sobre una JVM compatible. En QA permite escribir automatización, utilidades y validadores.

Explicación paso a paso

  1. Distingue lenguaje (Java) de herramienta de pruebas (Selenium).
  2. Un programa expresa reglas mediante clases y métodos.
  3. Un test automatizado compara resultados observados contra expectativas.
Ejemplo · Java / terminal
class SmokeCheck {
  public static void main(String[] args) {
    boolean passed = true;
    System.out.println("PASS: " + passed);
  }
}
Resultado / comportamiento: PASS: true
Enfoque QA / entrevista

Q02BásicoJava y JVM

RESPUESTA EXPLICADA

Q21IntermedioBúsqueda binaria

¿Cómo implementas binary search iterativo?

RESPUESTA EXPLICADA

Mantén límites low y high; calcula mid sin overflow; reduce el intervalo hasta encontrar el objetivo o agotarlo.

Explicación paso a paso

  1. Inicializa low=0 y high=n−1.
  2. Calcula mid=low+(high−low)/2.
  3. Ajusta low/high según comparación.
Ejemplo · Java / terminal
static int find(int[] a, int target) {
  int low=0, high=a.length-1;
  while (low <= high) {
    int mid=low+(high-low)/2;
    if (a[mid]==target) return mid;
    if (a[mid]<target) low=mid+1;
    else high=mid-1;
  }
  return -1;
}
Resultado / comportamiento: find(new int[]{2,4,6}, 4) → 1
Enfoque QA / entrevista

Tiempo O(log n); memoria O(1); la entrada debe estar ordenada.

Q23IntermedioHashMap

Q41AvanzadoLinked List

¿Cómo detectas un ciclo en una lista enlazada con O(1) memoria?

RESPUESTA EXPLICADA

El algoritmo de Floyd utiliza dos punteros: slow avanza uno y fast dos. Si se encuentran, existe ciclo.

Explicación paso a paso

  1. Inicializa slow y fast en head.
  2. Avanza slow una posición y fast dos.
  3. Si coinciden, hay ciclo; si fast llega a null, no hay.
Ejemplo · Java / terminal
Node slow=head, fast=head;
boolean cycle=false;
while(fast!=null && fast.next!=null){
  slow=slow.next; fast=fast.next.next;
  if(slow==fast){cycle=true;break;}
}
Resultado / comportamiento: cycle = true si existe ciclo
Enfoque QA / entrevista

Tiempo O(n), espacio O(1).
